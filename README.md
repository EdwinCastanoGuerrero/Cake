# Confeitaria Colômbia

Site criado para a Confeitaria Colômbia, mostrando um pouco dos produtos, história e serviços oferecidos.

## Tecnologias

React 19
Tailwind
Js
JavaScript
Bibliotecas React

## Desenvolvimento

Requer Node.js e npm.

```sh
npm install
npm run dev
```

## Verificação e build

```sh
npm test
npm run lint
npm run build
npm run preview
```
